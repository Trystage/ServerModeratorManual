# 管理组(协管，建筑师组)要求
基于TrystageBedwars服务器的开放性与复杂度，为了玩家的游戏体验与舒适，对管理组进行以下要求:

## 与玩家交互

### 减少与玩家正面交互
在服务器内，如需与玩家进行游戏，检测或调研，请使用小号或其他方式。请勿使用管理员账号参与活动(例如使用GM账号进入游戏和玩家pvp)，在大厅或观战时，请开启隐身。
在交流群内,如遇群友不合理行为,请勿直接使用管理员权限进行处罚,应当使用管理内群的机器猫(/tbw mute 某人 时长 原因)进行处罚

### 规范且合理地使用权力
在服务器或群内对玩家进行处罚或取消处罚时，请使用规范且合理的封禁原因，例如:
**玩家刷屏**
- 请使用: /mute Player spam(Spamming template)或群内/tbw mute 114514 600 Spamming
- 请勿使用: /mute Player 刷屏 365d或群内/tbw mute 114514 6000 太esu了

请勿不合理使用管理员权力,例如:
在服务器内,未与玩家事先商量且同意后擅自使用管理员权力(例如全员开启创造模式,或与玩家起争执直接以不合理缘由封禁玩家)

### 开展活动
在主播或玩家申请开展活动后,可对单场或多场游戏进行特殊活动行为(例如启用竞赛殿堂,并临时为竞赛活动玩家开放rbw功能)
请勿在未经玩家或管理允许的情况下对玩家进行活动类行为

## 配置服务器

### 格式规范
请勿使用及其简短的缩写或各类无关名词制作服务端内容
例如:
- kiiya使用 cat作为category的变量名,vs作为VersionSupport变量名
- int 奥特曼 = 1;
- 菜单配置文件内使用 "tp" 作为 The Pit的物品id
- twin内使用 "sb.cnm" 作为聊天消息不合法的Message回复

### 过于庞大的屎山
请勿反复声明,或反复调用各类外部或复杂响应功能,或堆积过多同类型功能,或在需被经常调用的功能里复杂化代码
例如:
- if (getPlugin().xxx(getPlugin()) && getPlugin().xxxx(getPlugin()))
- twin里堆积大量同一种对象(例如有20多个不同位置的"&aDuels")
- 故意制造卡服或后台大量刷屏功能

### 泄露(或破解)服务器内功能
请勿将服务器内的任何文件,服务端,插件,模组,服务端或插件输出,日志或各类服务器特殊及私用项目向外部分发,或对服务器管理组以外的人进行传播
例如:
- 将服务器插件报错信息截图问友商怎么解决
- 将服务器竞技场打包带走(或送给隔壁友商)
- 将服务器设为private的仓库插件构建或向友商分享源代码
- 将Felix二次分发或泄露
- 将服务器付费插件(或特殊插件)泄露向他人或挪用

## 其他行为

### 遵守玩家规则
为玩家定义的规则,并非管理员可以肆意践踏,在服务器环境内进行辱骂,开挂,发原神一键下载链接等一切违反[玩家行为规范与处罚条例](/PlayerRules.md)的行为,需接受相比玩家更严重的处罚(例如降低权限,取消管理组职务).

### 自身要求
禁止管理员在外进行可造成对服务器较大负面影响的非法活动,例如:
- 编写外挂并分发
- 在外月抛被抓
- 使用非法手段获取他人信息并传播
